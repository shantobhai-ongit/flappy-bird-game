# 🐦 Flappy Bird Game

A fun and interactive Flappy Bird game built with HTML, CSS, and JavaScript. Play it right in your browser!

## 🎮 How to Play

- **Click or Tap** to make the bird jump
- **Avoid the pipes** to keep playing
- **Get the highest score** possible
- **Your best score is saved** automatically

## 🎯 Features

✨ **Simple & Fun Gameplay** - Easy to learn, hard to master  
💾 **Score Tracking** - Your best score is saved in your browser  
📱 **Mobile Friendly** - Works on phones, tablets, and desktop  
🎨 **Beautiful Design** - Modern UI with smooth animations  
⚡ **Smooth Performance** - Optimized for all devices  

## 🚀 Play Online

Visit your game here: **https://shantobhai-ongit.github.io/flappy-bird-game/**

## 📦 Files

- `index.html` - Game structure
- `style.css` - Game styling and layout
- `script.js` - Game logic and mechanics

## 🛠️ How It Works

The game uses:
- **HTML5 Canvas** for graphics
- **JavaScript** for game logic
- **LocalStorage** for saving high scores

## 🎓 Learning

This is a beginner-friendly project that teaches:
- Game loops and animations
- Collision detection
- DOM manipulation
- Canvas drawing
- Local storage
